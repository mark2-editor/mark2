# Appearance and settings

Make the writing space comfortable before a long session. Appearance settings affect how Mark2 looks; editor settings control layout and saving behavior.

## Choose a theme

Open **Settings → Appearance** or use the **Themes** menu on macOS.

| Light themes | Dark themes |
| --- | --- |
| Light, Solarized Light, Crisp, Paper, Newsprint, Warm | Dark, Nord, Solarized Dark, Dracula, Monokai, One Dark, Gruvbox Dark, Catppuccin Mocha |

<Mark2DocImage src="/mark2-settings-appearance.png" alt="Mark2 Appearance settings with theme, code theme, font, interface scale, and texture controls." caption="Adjust colors and typography together in Appearance settings." />

Choose a theme with readable contrast in your environment. Theme choice changes presentation, rather than converting your Markdown into a theme-specific file format.

## Adjust fonts and scale

Set the editor font and text size for prose, and the code font separately for code. Use a preset or enter the name of a font installed on your computer.

Interface scale changes the size of the app's controls. If the whole interface feels too small, adjust it instead of only increasing the document text size. The **View** menu also provides zoom controls and **⌘0** to reset zoom.

If a custom font does not appear, check that it is installed and its name is correct, then try a preset to isolate the issue.

## Set an independent code theme

Enable the independent code theme option when you want code blocks to use a separate color scheme. Check both text contrast and the distinction between syntax colors in the selected theme.

## Add background texture

Choose a texture and adjust its strength. A low intensity can add a paper feel while keeping dense text and tables readable.

<Mark2DocImage src="/mark2-appearance-paper.png" alt="A Markdown document displayed with the Mark2 Paper theme." caption="The Paper theme applied to a Markdown document." />

## Arrange the editor

In **Settings → Editor**:

- Align the document to the center or left.
- Show or hide the formatting toolbar.
- Put the outline on the left or right.
- Set auto-save to Off, After delay, or On focus change.

The **View** menu can toggle sidebars, the outline, and the toolbar. For focused writing, hide panels you are not currently using. Bring the outline back when navigating a long document.
