# Editor basics

Mark2 has two ways to work with the same document:

- **Visual editor** — write on a clean page and use the toolbar for formatting.
- **Source mode** — see the plain Markdown text behind the formatted page.

You can switch between them without creating a second copy of the document.

## Write and format

Use the toolbar or the **Edit** menu for headings, bold, italic, lists, quotes, code, links, images, and tables. You do not need to learn Markdown symbols to use these tools.

Mark2 can display tables, task lists, code, math, Mermaid diagrams, and images in the page. The **Insert** menu is useful when you would rather choose an item than type its syntax.

## Source mode

Choose **Toggle source mode** when you want to see or edit the original text. It is especially useful for document metadata at the top of a file, code blocks, or a link that needs a precise change. Switch back to the visual editor when you want to continue writing on the rendered page.

## Find your way around

The **Outline** panel lists the document headings and lets you jump to a section. **Search** looks through the open document; **Global search** looks through the whole workspace.

The toolbar, sidebars, and outline can be shown or hidden from the **View** menu or Settings. These choices only change the workspace layout, not the document.
