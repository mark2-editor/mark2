# Mark2 Help

Mark2 is a calm workspace for writing, reviewing, and publishing documents. No technical background is required.

## Start here

1. Open a Markdown file or folder. Markdown is ordinary text with a few simple formatting marks; you can use the toolbar instead of memorizing them.
2. Write in the visual editor.
3. Save when you are ready, or turn on auto-save in Settings.

Choose a guide based on what you want to do:

- [Editor basics](./editor) — Write, format, search, and move around a document.
- [AI assistant](./ai) — Ask for help with a draft or receive gentle writing suggestions.
- [Export](./export) — Turn a document into a PDF, image, web page, or editable Markdown file.
- [Local history](./history) — Find an earlier version of a document saved on this computer.
- [Git workflow](./git) — Keep a clear record of changes to a group of files.
- [Appearance](./appearance) — Choose a comfortable theme, font, and layout.

Mark2 works with normal files on your computer. The app keeps local history and AI conversations separately from those files.
