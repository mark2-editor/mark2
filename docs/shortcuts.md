# Keyboard shortcuts

These shortcuts are for macOS. **⌘** means Command, **⇧** means Shift, and **⌥** means Option. The in-app reference is available from **Help → Keyboard shortcuts** and Settings.

## Files and export

| Action | Shortcut |
| --- | --- |
| New document | **⌘N** |
| Open a file | **⌘O** |
| Quick open | **⌘P** |
| New window | **⌘⇧N** |
| Save | **⌘S** |
| Save as | **⌘⇧S** |
| Close document | **⌘W** |
| Export PDF | **⌘⇧E** |
| Print | **⌘⇧P** |
| Settings | **⌘,** |

## Editing and search

| Action | Shortcut |
| --- | --- |
| Undo | **⌘Z** |
| Redo | **⌘⇧Z** |
| Bold | **⌘B** |
| Italic | **⌘I** |
| Find in document | **⌘F** |
| Find next / previous | **⌘G** / **⌘⇧G** |
| Replace | **⌘⌥F** |
| Global search | **⌘⇧F** |

## Visual editor formatting

These bindings apply while the visual editor has focus. Source mode and other controls may handle some keys differently.

| Action | Shortcut |
| --- | --- |
| Inline code | **⌘E** |
| Strikethrough | **⌘⌥X** |
| Heading level 1–6 | **⌘⌥1** through **⌘⌥6** |
| Ordered list | **⌘⌥7** |
| Bullet list | **⌘⌥8** |
| Code block | **⌘⌥C** |
| Blockquote | **⌘⇧B** |
| Indent / outdent list item | **Tab** / **⇧Tab**, or **⌘]** / **⌘[** |
| Next / previous table cell | **Tab** / **⇧Tab** |
| Line break within a block | **⇧Enter** |

## AI and navigation

| Action | Shortcut |
| --- | --- |
| Request inline completion | **⌘J** |
| Accept visible completion | **Tab** |
| Dismiss visible completion | **Esc** |
| Toggle left sidebar | **⌘⇧L** |
| Toggle right sidebar | **⌘⇧R** |
| Reset zoom | **⌘0** |
| Zoom in / out | **⌘+** / **⌘−** |

AI completion must be enabled and configured before its shortcuts can request a suggestion. A visible completion takes priority over normal Tab navigation.

To switch source mode, use **View → Source mode**. No shortcut is listed here for actions without a verified default key binding.

## If a shortcut does not work

Click in the document first. A text field, dialog, or AI prompt can handle the key differently. Check the app menu for the action and verify that macOS or another utility has not captured the same shortcut.
