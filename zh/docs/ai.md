# AI 助手

Mark2 提供两种可选 AI 功能：**Agent** 用于改写、查询和文档任务；**行内补全**在写作时提供简短的续写建议。

## 配置服务商与模型

**服务商**提供 AI 服务，**模型**是该服务中的具体 AI。**API key** 用于验证请求，应妥善保管。

1. 打开 **设置 → AI**，如果 AI 已关闭，先启用。
2. 添加 OpenAI、DeepSeek、Anthropic、Gemini 或自定义 OpenAI 兼容服务。
3. 输入服务商提供的 API key。部分自定义服务允许不填密钥。
4. 获取模型列表，或添加账号可使用的模型。
5. 选择 Agent 使用的服务商与模型，测试连接。

自定义服务还需要配置 API 端点。端点与模型必须符合服务所支持的协议。连接测试通过是基本检查；Agent 的工具任务还取决于模型能力。

::: info 服务用量
AI 请求使用配置的服务凭据，访问权限、额度与费用由该服务决定。Mark2 的编辑与导出无需配置 AI。
:::

## 提出明确的任务

打开右侧 AI 面板，说明要处理的内容、修改范围与预期结果。

| 目标 | 请求示例 |
| --- | --- |
| 缩短内容 | “将引言压缩为两段，保留所有事实信息。” |
| 总结笔记 | “将这些笔记整理为决议、待确认问题和下一步行动。” |
| 翻译 | “将这一节翻译为英文，保留命令和文件名。” |
| 调整结构 | “先给出指南的大纲建议，不要修改文件。” |
| 检查可读性 | “找出新用户可能误解的句子，并说明原因。” |

从范围明确的单项修改开始。使用结果前，检查含义、事实与语气是否符合要求。

## 提供上下文

当前文档或选中的段落可以提供上下文。在输入框中输入 **@** 引用工作区文件，输入 **/** 查看改写、总结、翻译、校对等可用技能。

明确说明范围，例如“只修改结论”。处理长文档时，引用与任务有关的章节或文件，避免假定模型能够一次读取全部内容。

Agent 可以读取和搜索工作区文件，并在相关工具可用时查询网页。引用内容与工具结果可能进入发送给服务商的请求。详情见[隐私与 AI](./privacy)。

## 选择权限模式

新会话的默认模式在 AI 设置中配置，也可以针对当前会话调整。

| 模式 | 工具行为 |
| --- | --- |
| **Default（默认）** | 只读工具可以执行，写入工具需要确认 |
| **Plan（规划）** | 允许只读操作，阻止写入工具 |
| **Auto（自动）** | 在应用保护规则范围内，写入工具无需逐项确认 |

仅需要分析或大纲时使用 Plan。使用 Default 时，先检查申请执行的操作，再决定是否批准。任务适合更宽的操作权限时，才使用 Auto。

提供文档变更视图时，先检查修改再应用。工具执行权限与检查生成文本是两个不同环节。

## 使用行内补全

在 **设置 → AI → 行内补全** 中启用功能，并选择触发方式：

- **自动**：停止输入一段时间后请求建议，可调整等待时长。
- **手动**：通过 **⌘J** 请求建议。

建议以浅色预览文字显示。按 **Tab** 接受，按 **Esc** 关闭，或继续输入。默认跟随 Agent 的服务商与模型；高级设置允许单独选择，并调整建议长度上限。

如果希望减少自动请求，可以使用手动模式。需要停止两种 AI 功能的请求时，在设置中关闭 AI。

## 请求失败时

检查服务商、模型、API key、端点、网络连接与服务额度。如果普通聊天正常、工具任务失败，检查模型是否支持相关工具调用。

逐项排查见 [AI 常见问题](./troubleshooting#ai-没有响应)，相关按键见[键盘快捷键](./shortcuts#ai-与界面导航)。
