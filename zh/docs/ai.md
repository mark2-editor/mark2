# AI 助手

Mark2 提供两种 AI 工具：**AI Agent** 用来完成一项完整的请求；**行内补全**则是在你写作时给出简短建议。两者都可以按需开启。

## 先了解三个词

- **服务商**：提供 AI 服务的公司或平台。
- **模型**：服务商提供的某一个 AI 版本。
- **API Key**：服务商发给你的访问密钥，可以把它当作密码保管。

## 配置 AI

打开“设置 → AI”，然后：

1. 添加一个服务商。
2. 如果需要，填写 API Key。
3. 添加或自动发现模型。
4. 测试连接，并选择要使用的服务商和模型。

Mark2 支持 OpenAI、DeepSeek、Anthropic、Gemini，以及兼容 OpenAI 接口的自定义服务。不了解区别时，可以先选择与你已有账号对应的内置服务商。

## 让 AI Agent 帮你处理内容

从编辑器右侧边栏打开 AI 面板。你可以让它改写、续写、翻译、总结、解释或润色文字。当前文档或选中的段落可以作为参考内容。

在输入框中输入 `/` 可以查看可用命令，输入 `@` 可以选择工作区中的文件作为补充内容。Agent 也可以读取和搜索工作区文件，或在需要时搜索网页。

Mark2 不会悄悄修改你的文件。执行写入操作前会请求确认，文档修改也可以先查看差异再应用。

## 获得写作建议

在“设置 → AI → 行内补全”中开启补全，然后选择：

- **自动** — 暂停输入后显示建议。
- **手动** — 只有主动请求时才显示建议。

建议会以较浅的预览文字显示。觉得有用就接受，不需要时继续输入即可忽略。默认使用 Agent 的服务商和模型，也可以在高级设置中单独选择。
