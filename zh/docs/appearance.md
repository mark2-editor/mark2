# 外观与设置

外观设置控制颜色、字体和界面呈现；编辑器设置控制布局与保存行为。可根据阅读习惯和显示设备分别调整。

## 选择主题

打开 **设置 → 外观**，或使用 macOS 上的 **主题** 菜单。

| 明亮主题 | 深色主题 |
| --- | --- |
| Light、Solarized Light、Crisp、Paper、Newsprint、Warm | Dark、Nord、Solarized Dark、Dracula、Monokai、One Dark、Gruvbox Dark、Catppuccin Mocha |

<Mark2DocImage src="/mark2-settings-appearance.png" alt="Mark2 外观设置中的主题、代码主题、字体、界面缩放与纹理控件。" caption="在外观设置中统一调整配色与字体。" />

选择适合当前环境、对比清晰的主题。主题改变显示方式，不会将 Markdown 转换为主题专用的文件格式。

## 调整字体与缩放

分别设置正文和代码字体，调整编辑器文字大小。可以使用预设，也可以输入已安装字体的名称。

界面缩放调整控件尺寸。如果整个界面偏小，应调整界面缩放，而不只是正文大小。**显示** 菜单也提供缩放控制，按 **⌘0** 恢复默认缩放。

自定义字体未生效时，检查字体是否安装、名称是否正确，再用预设字体排除问题。

## 独立设置代码主题

需要单独的代码配色时，启用独立代码主题。检查代码文字与背景的对比，以及不同语法颜色是否易于区分。

## 设置背景纹理

选择纹理并调整强度。较低强度可以保留纸张质感，同时避免影响长段落与表格的可读性。

## 调整编辑布局

在 **设置 → 编辑器** 中：

- 设置文档居中或左对齐。
- 显示或隐藏格式工具栏。
- 将大纲放在左侧或右侧。
- 选择关闭、延迟或失去焦点时自动保存。

通过 **显示** 菜单控制侧边栏、大纲和工具栏。写作时可以隐藏暂时不用的面板，导航长文档时再显示大纲。
