# 编辑器基础

Mark2 为同一份 Markdown 文档提供两个视图：可视化编辑器用于编辑渲染后的页面，源码模式用于直接修改文本与语法。

## 设置文本格式

选中内容后，通过格式工具栏或 **格式** 菜单应用样式。插入新的内容块时，先将光标放到目标位置，再选择标题、列表、引用或代码块。

| 内容 | 使用方式 |
| --- | --- |
| 文档标题或章节 | **格式 → 标题** |
| 重点内容 | 加粗（**⌘B**）或斜体（**⌘I**） |
| 操作步骤或并列要点 | 有序列表或无序列表 |
| 引用内容 | 引用块 |
| 简短代码名称 | 行内代码 |
| 完整代码示例 | 带语言标记的代码块 |
| 对比信息 | 表格 |
| 参考资料或图片 | **插入** 菜单中的链接或图片 |

也可以在输入时使用 Markdown 标记创建常见结构。粘贴完整 Markdown 示例时，建议使用源码模式。

## 编辑列表与表格

- 在列表中按 **Enter** 创建下一项。
- 使用 **Tab** 与 **Shift+Tab** 缩进或提升列表项。
- 在表格中，**Tab** 移动到下一个单元格，**Shift+Tab** 移动到上一个单元格。
- 位于表格最后一个单元格时，**Tab** 可以添加新行。
- 使用 **Shift+Enter** 在内容块内换行。

如果正在显示 AI 补全建议，**Tab** 会优先接受建议。需要正常进行列表或表格导航时，先按 **Esc** 关闭建议。

## 切换源码模式

选择 **显示 → 源代码模式**。该模式适合检查链接目标、编辑 frontmatter、调整代码块或查看 Markdown 语法。

源码模式与可视化编辑器共用文档，不会创建第二份文件。在任一模式中都可以按 **⌘S** 保存。

::: tip 复杂文档先保留副本
如果文档使用其他工具的自定义语法或 HTML，先在源码模式中检查，并核对保存结果，再替换唯一副本。不同 Markdown 渲染器对扩展语法的处理可能不同。
:::

## 导航长文档

使用标题建立清晰结构。**大纲**面板列出文档中的标题，点击即可跳到对应章节。

通常使用一个一级标题作为文档名称，二级标题划分主要章节，三级标题组织细节。标题结构也用于生成导出目录。

通过 **显示** 菜单控制大纲、工具栏与侧边栏的显示。在 **设置 → 编辑器** 中选择大纲位置和文档对齐方式。

## 查找与替换

| 操作 | macOS 快捷键 |
| --- | --- |
| 搜索当前文档 | **⌘F** |
| 下一个匹配 | **⌘G** |
| 上一个匹配 | **⌘⇧G** |
| 打开替换 | **⌘⌥F** |
| 搜索工作区 | **⌘⇧F** |
| 快速打开文件 | **⌘P** |

替换完成后检查结果，再保存文档。短词可能出现在较长单词或链接中，需要留意替换范围。

## 撤销、保存与恢复

**⌘Z** 撤销近期编辑，**⌘⇧Z** 重做。撤销适用于当前编辑过程；[本地历史](./history)用于比较和恢复旧版本，[Git](./git)用于记录项目节点。

保存与自动保存的区别见[文件与工作区](./files)。常用语法见 [Markdown 示例](./markdown)。
