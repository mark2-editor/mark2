# 编辑器基础

Mark2 有两种编辑方式，但它们使用的是同一份文档：

- **所见即所得编辑器** — 像在纸上写作一样，使用工具栏完成格式设置。
- **源码模式** — 查看格式化页面背后的 Markdown 原文。

你可以随时切换，不会因此产生两份文档。

## 写作与格式化

使用工具栏或“编辑”菜单，可以设置标题、粗体、斜体、列表、引用、代码、链接、图片和表格。你不需要记住 Markdown 符号。

Mark2 可以显示表格、任务列表、代码、数学公式、Mermaid 图表和图片。对于适合通过菜单创建的内容，可以使用“插入”菜单。

## 源码模式

需要查看或直接修改原始文字时，选择“切换源码模式”。它适合修改文件开头的文档信息、代码块，或需要精确调整的链接。完成后切回所见即所得编辑器即可继续写作。

## 浏览文档

“大纲”面板会列出文档标题，点击即可跳转到对应章节。“搜索”只查找当前文档；“全局搜索”会查找整个工作区。

工具栏、侧边栏和大纲都可以通过“视图”菜单或设置显示、隐藏。这些选择只改变界面布局，不会改变文档内容。
