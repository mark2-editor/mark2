# 导出文档

文档完成后，打开“文件 → 导出”，选择适合用途的格式：

- **PDF** — 适合打印或作为最终文档发送。
- **PNG** — 将渲染后的页面保存为图片。
- **HTML** — 保存为可以在浏览器中打开的网页。
- **Markdown** — 保存为可以继续编辑的文字文件。

你也可以从编辑器菜单复制 Markdown 源码或带格式的富文本。

## 导出 PDF

PDF 会按照 Mark2 中看到的页面导出，包括标题、表格、代码、图片、数学公式和 Mermaid 图表等内容。

<figure class="mark2-doc-shot-single"><img src="/mark2-export-pdf.png" alt="从 Mark2 导出的 PDF 在 Preview 中打开。" /><figcaption>Mark2 将渲染后的文档导出为带目录的 PDF。</figcaption></figure>

导出前，可以打开“设置 → 导出”调整：

- 页面尺寸：A4、A3、A5、US Letter 或 US Legal
- 上、下、左、右边距
- 是否根据文档标题自动生成目录

然后选择“文件 → 导出 → PDF”。导出文件默认使用当前文件名。

## 应该选择哪种格式？

以后还要继续修改，选择 Markdown；希望版式固定，选择 PDF；希望在浏览器中打开，选择 HTML；只需要一张图片，选择 PNG。
