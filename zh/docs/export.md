# 导出文档

使用 **文件 → 导出** 将文档保存为适合分享的格式。根据读者的需要，选择固定版式、图片、浏览器页面或可编辑的 Markdown。

## 选择格式

| 格式 | 适用场景 | 需要检查 |
| --- | --- | --- |
| PDF | 打印与分享固定版式 | 分页、页边距、表格与链接 |
| PNG | 分享渲染后的图片 | 图片尺寸与可读性 |
| HTML | 在浏览器中阅读 | 渲染结果、链接与引用资源 |
| Markdown | 在其他工具中继续编辑 | 源码语法与图片路径 |

只需要转移内容时，也可以通过编辑器菜单复制原始 Markdown 或格式化的富文本。

## 导出前检查

1. 保存最新草稿。
2. 在可视化编辑器中检查标题层级、图片加载与表格宽度。
3. 确认代码、公式和 Mermaid 图表正常渲染。
4. 删除未完成的备注，检查读者需要使用的链接。

导出依赖可渲染的内容。先处理缺失图片和图表语法错误，再导出。

## 配置页面

在导出或打印前打开 **设置 → 导出**：

- **纸张大小**：A4、A3、A5、US Letter、US Legal。
- **页边距**：上、下、左、右分别设置。
- **目录**：根据文档标题生成目录。

目录设置用于 PDF、HTML、PNG 和打印。页面设置也影响 PDF 与 PNG 输出。标题应具有明确含义，并保持一致的层级。

## 导出 PDF

1. 确认页面设置。
2. 选择 **文件 → 导出 → PDF**，或按 **⌘⇧E**。
3. 选择保存位置与文件名。
4. 使用“预览”打开结果，逐页检查。

检查宽表格、长代码行、截断内容、分页位置和图表空间。必要时增大纸张、调整页边距，或简化内容。

## 导出 PNG 或 HTML

在 **文件 → 导出** 中选择格式并保存。用图片查看器打开 PNG，用浏览器打开 HTML，检查读者实际看到的结果。

分享 HTML 或 Markdown 前，检查图片引用。你电脑上的本地路径可能无法在读者电脑上访问。将必要的本地资源与文档一起分享，或使用适当的在线图片。

## 导出 Markdown

Markdown 保留可编辑的文本与语法，不固定页面版式。适合继续修改，或通过其他 Markdown 工具发布。

在源码模式中检查工具专用语法与相对路径。数学公式、Mermaid 等扩展能否显示，取决于目标工具。

## 打印

需要系统打印流程时，使用 **文件 → 打印**（**⌘⇧P**）。确认前检查预览与打印目标。

输出问题见[导出问题排查](./troubleshooting#导出内容缺失或版式不符合预期)。
