# 文件与工作区

Mark2 使用电脑上的本地文件。可以打开单篇文档进行编辑，也可以打开文件夹，集中处理相关文档。

## 选择打开方式

| 任务 | 操作 |
| --- | --- |
| 编辑单个文件 | **文件 → 打开**，或 **⌘O** |
| 浏览一组相关文档 | **文件 → 打开文件夹** |
| 新建草稿 | **文件 → 新建**，或 **⌘N** |
| 快速切换工作区文件 | **文件 → 快速打开**，或 **⌘P** |
| 使用另一个窗口 | **文件 → 新建窗口**，或 **⌘⇧N** |

文件夹树展示工作区文件，已打开文件列表保留当前使用的文档。按 **⌘W** 关闭的是文档视图，不会删除磁盘文件。

## 组织文档项目

将相关文档和图片放在同一个项目目录中。例如：

```text
project-notes/
  overview.md
  meetings/
    kickoff.md
  guides/
    setup.md
  assets/
    screenshot.png
```

使用含义明确的文件名，通过 `[设置指南](./guides/setup.md)` 这样的相对链接关联文档。移动或重命名文件后，检查引用原路径的链接。

## 理解草稿与保存

**草稿**是 Mark2 中正在编辑的内容；**已保存文件**是写入磁盘的版本；**历史快照**是本地历史保留的旧版本。

按 **⌘S** 手动保存。新文档需要先确定名称和保存位置，才会成为磁盘文件。使用 **文件 → 另存为**（**⌘⇧S**）保存到其他名称或位置。

在 **设置 → 编辑器** 中选择自动保存模式：

| 模式 | 写入磁盘的时机 |
| --- | --- |
| 关闭 | 通过 **⌘S** 手动保存；此前修改保留为草稿 |
| 延迟保存 | 停止输入并达到设置的延迟后 |
| 失去焦点时 | 切换文档、切换应用或最小化窗口时 |

::: tip 分享前先保存
如果其他应用、Git 或备份工具需要读取最新内容，先保存文档。编辑器中显示的草稿可能比磁盘文件更新。
:::

自动保存与本地历史分别配置。每次自动写入磁盘，不一定都会新增历史快照。详情见[本地历史](./history)。

## 管理图片资源

可以通过 **插入** 菜单添加图片，也可以粘贴或拖入图片。在 **设置 → 图片** 中配置粘贴和拖入图片的存储位置。

需要便于迁移的文档时，将本地图片与项目放在一起，并在源码模式中检查路径。分享 Markdown 文件时，同时提供引用的图片资源。

图片上传是可选方式。配置并启用后，粘贴或拖入的图片会发送到指定的 S3 兼容存储，文档中使用在线链接；上传失败时回退到本地保存。启用前，请查看[其他联网功能](./privacy#其他联网功能)。

## 搜索工作区

**⌘F** 搜索当前文档，**⌘⇧F** 进行全局搜索。文档较多时，可以使用明确的文件名、关键词或短语缩小结果范围。

在单篇文档中，通过[大纲面板](./editor#导航长文档)按标题跳转。

## 保存与备份

本地历史用于恢复这台电脑上的旧文本，Git 用于记录项目的明确变更节点。重要文件与图片仍应有独立备份；未保存草稿和本地历史不等于另一台设备上的副本。

继续阅读[本地历史](./history)或 [Git 工作流](./git)。
