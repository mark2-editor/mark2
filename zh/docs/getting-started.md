# 快速开始

本指南介绍安装 Mark2、创建文档、保存 Markdown 文件和导出 PDF 的基本流程。

## 安装 Mark2

1. 打开 [Mark2 发布页面](https://github.com/mark2-editor/mark2/releases/latest)。
2. 下载适合你的 Mac 的 macOS 安装包。如果提供不同架构的文件，M 系列芯片选择 **Apple Silicon / aarch64**，Intel 芯片选择 **Intel / x64**。芯片信息可在 **苹果菜单 → 关于本机** 中查看。
3. 打开下载的 `.dmg`，将 Mark2 移入 **应用程序**。
4. 从应用程序目录打开 Mark2。

如果 macOS 阻止打开应用，请查看[安装问题排查](./troubleshooting#无法打开-mark2)。目前公开下载暂时仅支持 macOS。

## 创建第一篇文档

1. 选择 **文件 → 新建**，或按 **⌘N**。
2. 输入标题和正文，通过 **格式 → 标题** 设置标题级别。
3. 使用工具栏或 **格式** 菜单添加项目列表。
4. 按 **⌘S**，选择保存位置，将文件保存为 `first-note.md`。

保存后得到的是 Markdown 文件，可以在其他文本编辑器中继续编辑，也可以加入现有项目。

::: tip 练习建议
创建一篇会议记录，包含标题、三项决议和一个任务清单。使用实际内容，有助于熟悉常用格式和保存流程。
:::

## 打开现有文件或文件夹

使用 **文件 → 打开**（**⌘O**）编辑单个文件；使用 **文件 → 打开文件夹**，在侧边栏中浏览一组文档。

打开文件夹后，**⌘P** 可快速打开文件，**⌘⇧F** 可搜索工作区。组织文档的方法见[文件与工作区](./files)。

## 查看 Markdown 源码

选择 **显示 → 源代码模式**，直接编辑 Markdown 文本。切回可视化模式后，继续编辑渲染后的页面。两个模式使用同一份文档。

可在源码模式中输入以下内容：

```markdown
# 第一篇笔记

记录一个需要保留的想法。

- [ ] 完成初稿
- [ ] 检查表达
- [ ] 分享文档
```

表格、代码、公式和图表的写法见 [Markdown 示例](./markdown)。

## 配置保存与恢复

- **⌘S** 将当前文档写入磁盘。
- **设置 → 编辑器 → 自动保存** 控制自动写入磁盘的时机。
- **设置 → 存储 → 启用本地历史** 控制历史快照。

草稿、已保存文件和历史快照各有用途。在依赖自动保存之前，请先了解[保存行为](./files#理解草稿与保存)。

## 导出 PDF

1. 保存当前文档。
2. 打开 **设置 → 导出**，选择纸张大小与页边距。
3. 选择 **文件 → 导出 → PDF**（**⌘⇧E**）。
4. 保存 PDF，并在“预览”中检查导出结果。

其他导出格式与分享前的检查方法见[导出文档](./export)。

## 按需配置 AI

AI 是可选功能。需要使用时，打开 **设置 → AI**，添加服务商、配置模型并测试连接。随后打开右侧 AI 面板，输入具体任务。

例如：“将这段内容压缩为两段，保留所有事实信息。”处理敏感内容前，请阅读 [AI 助手](./ai)和[隐私与 AI](./privacy)。
