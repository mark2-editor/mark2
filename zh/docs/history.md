# 本地历史

本地历史在这台电脑上保存文档旧版本，用于比较修改或恢复之前的内容。

它与 [Git](./git) 不同：本地历史为单篇文档记录快照，Git 为整个仓库记录明确的提交节点。

## 启用与配置快照

打开 **设置 → 存储**：

| 设置 | 作用 |
| --- | --- |
| 启用本地历史 | 是否记录历史快照 |
| 每个文件的最大版本数 | 每篇文档保留 10、25 或 50 个版本 |
| 总存储上限 | 200 MB、500 MB、1 GB 或无限制 |
| 自动保存历史间隔 | 自动保存可以新增快照的频率 |

启用历史后，手动保存会记录发生变化的内容，无需等待自动历史间隔。内容未变时，不会重复创建快照。自动保存遵循历史间隔设置，频繁写入磁盘不必产生同样频繁的快照。将自动历史间隔设为 **从不** 会停止自动快照，手动保存仍会记录版本。

达到保留上限时，旧快照会被清理。增加上限可以保留更多后续版本，但不能恢复已经移除的条目。

## 比较两个版本

1. 打开需要检查的文档。
2. 在编辑器侧边栏中打开 **历史**。
3. 根据时间与内容预览选择条目。
4. 选择对比目标：上一个版本、当前文档或其他历史条目。
5. 阅读差异，再决定是否恢复。

## 恢复旧版本

在比较视图中选择 **恢复**。Mark2 先将所选内容载入草稿，不会立即替换磁盘文件。

检查草稿并按需修改，确认后按 **⌘S** 写入文件。如果启用了自动保存，恢复的草稿也会按当前模式自动写入。需要充分检查且避免自动写入时，先关闭自动保存。

如果只需要旧版本中的某一段，可以通过比较找到对应文本，恢复该段内容，而不必替换整篇文档。

## 管理存储

存储设置显示本地占用情况，并支持清空历史。**清空所有本地历史**会删除已存快照，无法撤销。

历史仅存在于这台电脑，并受到保留上限影响。重要文档与图片应另行备份。Git 远端可以保留已推送的提交，但不会包含每个本地草稿或快照。

## 找不到某个版本时

检查当时是否启用了历史并保存文件。自动保存可能尚未达到快照间隔；较早的条目也可能因版本数或存储上限被移除。

磁盘保存方式见[文件与工作区](./files#理解草稿与保存)，项目提交见 [Git 工作流](./git)。
