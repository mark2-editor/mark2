# 本地历史

本地历史是 Mark2 自带的“后悔药”。它会把文档的旧版本保存在这台电脑上，方便你回看或找回较早的草稿。

它和 Git 不一样：本地历史主要保护单个文档；Git 则适合为一个文件夹或项目记录一系列修改。

## 开启历史

打开“设置 → 存储”，可以设置：

- **启用本地历史** — 开启或关闭自动保存旧版本。
- **每个文件的最大版本数** — 每个文件保留 10、25 或 50 个版本。
- **总存储限制** — 使用 200 MB、500 MB、1 GB 或不限制。
- **自动保存历史间隔** — 决定自动保存多久增加一个新版本。

Mark2 会在保存文档时记录版本。手动保存一定会记录一个版本；间隔设置可以避免频繁自动保存产生太多版本。

## 对比旧版本

在编辑器侧边栏打开当前文档的“历史”视图。每个条目会显示一小段内容预览和保存时间。选择条目，可以将它与前一个版本、当前文档或另一个历史版本进行对比。

## 恢复版本

在对比界面选择“恢复”。Mark2 会先把旧内容放入草稿，不会立刻替换磁盘上的文件。检查满意后，再保存即可。

你可以在“设置 → 存储”中清除全部本地历史。这个操作无法撤销。
