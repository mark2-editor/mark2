# Mark2 帮助文档

Mark2 是一款用于写作、审阅和发布文档的 Markdown 编辑器，不需要技术背景也可以使用。

## 从这里开始

1. 打开 Markdown 文件或文件夹。Markdown 本质上是普通文字加上一些简单的格式标记；你也可以直接使用工具栏。
2. 在所见即所得编辑器中写作。
3. 完成后手动保存，或在设置中开启自动保存。

你可以根据需要阅读以下指南：

- [编辑器基础](./editor) — 写作、格式化、搜索和文档导航。
- [AI 助手](./ai) — 让 AI 帮你处理草稿，或在写作时提供建议。
- [导出文档](./export) — 将文档变成 PDF、图片、网页或可继续编辑的 Markdown 文件。
- [本地历史](./history) — 找回保存在这台电脑上的旧版本。
- [Git 工作流](./git) — 为一组文件保留清晰的修改记录。
- [外观设置](./appearance) — 选择舒适的主题、字体和布局。

Mark2 使用你电脑上的普通文件。本地历史和 AI 对话由桌面应用单独管理。
