# 隐私与 AI

Mark2 编辑电脑上的本地文件。AI 与其他联网功能具有各自的数据流，应根据文档内容选择是否启用。

## 本地保存的数据

磁盘文档、工作草稿、本地历史与 Agent 会话记录保存在这台电脑上。基础编辑、格式设置、源码模式与导出无需 AI 服务。

如果文件位于其他应用同步的文件夹中，该应用仍可能上传文件。Mark2 使用本地文件不会改变云盘或备份软件的行为。

## AI 请求可能发送的内容

AI 请求发送到配置的服务商或自定义端点。根据任务，上下文可能包括：

- 输入的请求和相关对话历史。
- 当前文档或选中的段落。
- 通过 **@** 引用的文件。
- 文件读取、搜索或其他 Agent 工具返回的内容。
- 模型支持时，你添加的图片附件。

行内补全也会发送用于生成建议的上下文。自动模式可能在暂停输入后发起请求，手动模式在触发时请求。

::: info 本地文件与远端处理
Markdown 文件保存在本地，不代表使用外部 AI 时内容仍只留在本地。服务商如何处理和保留请求，由该服务的政策决定。
:::

不希望发起 AI 请求时，在设置中关闭 AI。希望保留 Agent、减少自动请求时，关闭行内补全或改为手动模式。使用本地兼容端点可以改变请求目标，但实际处理方式取决于配置的服务。

## 保护 API key

Mark2 在这台电脑上保存服务商配置。不要将 API key 写入 Markdown 文档、截图、公开仓库或问题反馈中。

从 Mark2 删除服务商会移除其保存的配置，但不会撤销服务商账号中的密钥。密钥泄露时，应在对应服务的账号中撤销或更换。

## 控制 Agent 工具

| 模式 | 写入工具策略 |
| --- | --- |
| Default（默认） | 请求确认 |
| Plan（规划） | 阻止写入 |
| Auto（自动） | 在应用保护规则范围内，无需逐项确认 |

三种模式都允许只读工具。“只读”描述的是文件修改权限；工具读取的内容仍可能发送给所选 AI 服务。

打开的工作区应尽量只包含任务所需文件。处理私密资料前，检查请求、引用文件与申请执行的操作。

## 其他联网功能

- **图片上传**：配置并启用后，粘贴或拖入的图片会上传到指定的 S3 兼容存储，文档使用在线 URL。
- **Git 远端**：获取、拉取、推送和同步会连接配置的远端。推送会发送对应提交与其中跟踪的内容。
- **Agent 网页工具**：网页查询会访问外部服务，并可能将返回内容纳入 AI 上下文。
- **应用更新**：Mark2 可以检查和下载应用更新，自动检查可在 **设置 → 通用** 中调整。

根据工作需要启用功能。使用图片上传时，分享 URL 前检查存储服务的访问权限。

## 私密文档的配置建议

1. 将敏感笔记保存在独立的本地文件夹中。
2. 关闭 AI，或只向配置的服务发送你已决定提供的内容。
3. 无需上传时，使用本地图片存储。
4. 推送 Git 仓库前检查暂存文件。
5. 为重要备份配置适当的访问控制。

配置步骤见 [AI 助手](./ai)、[文件与工作区](./files)和 [Git 工作流](./git)。
