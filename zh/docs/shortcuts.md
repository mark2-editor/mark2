# 键盘快捷键

本页列出 macOS 快捷键。**⌘** 表示 Command，**⇧** 表示 Shift，**⌥** 表示 Option。应用内也可以通过 **帮助 → 键盘快捷键** 或设置查看。

## 文件与导出

| 操作 | 快捷键 |
| --- | --- |
| 新建文档 | **⌘N** |
| 打开文件 | **⌘O** |
| 快速打开 | **⌘P** |
| 新建窗口 | **⌘⇧N** |
| 保存 | **⌘S** |
| 另存为 | **⌘⇧S** |
| 关闭文档 | **⌘W** |
| 导出 PDF | **⌘⇧E** |
| 打印 | **⌘⇧P** |
| 设置 | **⌘,** |

## 编辑与搜索

| 操作 | 快捷键 |
| --- | --- |
| 撤销 | **⌘Z** |
| 重做 | **⌘⇧Z** |
| 加粗 | **⌘B** |
| 斜体 | **⌘I** |
| 搜索当前文档 | **⌘F** |
| 下一个 / 上一个匹配 | **⌘G** / **⌘⇧G** |
| 替换 | **⌘⌥F** |
| 全局搜索 | **⌘⇧F** |

## 可视化编辑格式

以下按键在可视化编辑器获得焦点时适用。源码模式和其他控件可能使用不同的按键处理方式。

| 操作 | 快捷键 |
| --- | --- |
| 行内代码 | **⌘E** |
| 删除线 | **⌘⌥X** |
| 一级至六级标题 | **⌘⌥1** 至 **⌘⌥6** |
| 有序列表 | **⌘⌥7** |
| 无序列表 | **⌘⌥8** |
| 代码块 | **⌘⌥C** |
| 引用块 | **⌘⇧B** |
| 列表缩进 / 提升 | **Tab** / **⇧Tab**，或 **⌘]** / **⌘[** |
| 下一个 / 上一个表格单元格 | **Tab** / **⇧Tab** |
| 内容块内换行 | **⇧Enter** |

## AI 与界面导航

| 操作 | 快捷键 |
| --- | --- |
| 请求行内补全 | **⌘J** |
| 接受可见补全 | **Tab** |
| 关闭可见补全 | **Esc** |
| 切换左侧栏 | **⌘⇧L** |
| 切换右侧栏 | **⌘⇧R** |
| 恢复默认缩放 | **⌘0** |
| 放大 / 缩小 | **⌘+** / **⌘−** |

需要先启用并配置 AI 补全，才能通过快捷键请求建议。显示建议时，Tab 优先接受补全。

切换源码模式使用 **显示 → 源代码模式**。未验证默认按键的操作不在本页标注快捷键。

## 快捷键无效时

先点击文档，使编辑器获得焦点。文本框、对话框或 AI 输入区域可能以不同方式处理按键。也可以从菜单执行同一操作，并检查 macOS 或其他工具是否占用了该组合键。
