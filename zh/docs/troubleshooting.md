# 常见问题

根据实际现象选择以下条目。修改文件或设置前，先保存重要内容的副本。

## 无法打开 Mark2

1. 确认安装包来自[官方发布页面](https://github.com/mark2-editor/mark2/releases/latest)。
2. 在 **苹果菜单 → 关于本机** 中检查芯片；如果发布提供不同架构，确认下载正确。
3. 将 Mark2 移入应用程序目录再打开。
4. 如果 macOS 显示安全提示，在 **系统设置 → 隐私与安全性** 中检查，并按照系统提供的流程打开你信任的应用。
5. 下载不完整或文件损坏时，从发布页面重新下载。

保持 macOS 安全控制启用。反馈安装问题时提供准确的错误文字。

## 修改没有写入磁盘文件

草稿可能比磁盘文件更新。按 **⌘S**，确认保存位置，再通过其他应用重新打开文件。

检查 **设置 → 编辑器 → 自动保存**。关闭时需要手动保存；延迟模式等待输入暂停；失去焦点模式在切换离开时保存。

遇到权限错误时，使用 **另存为** 保存到你有写入权限的目录。确认原目录或外部磁盘可用且可写。详情见[文件与工作区](./files)。

## 本地历史为空或缺少条目

检查 **设置 → 存储 → 启用本地历史**，再手动保存一次。自动快照还取决于历史间隔，设为 **从不** 时不会自动记录。

旧条目可能因单文件版本上限或总空间限制被清理。清空历史会永久删除快照，调整上限不能恢复已删除条目。详情见[本地历史](./history)。

## AI 没有响应

按以下顺序检查：

1. AI 已启用，并已选择服务商和模型。
2. 服务商要求密钥时，已填写 API key。
3. 当前账号可以访问所选模型。
4. 自定义端点符合对应协议。
5. 连接测试通过，网络可以访问该服务。
6. 服务商未因额度、限流或账号限制拒绝请求。

普通聊天正常但工具失败时，检查模型是否支持工具调用。Agent 无法写入时，检查是否处于 Plan 模式，或在 Default 模式中等待确认。

只有行内补全失败时，检查它是否启用、独立服务商与模型配置是否正确，并在文档中按 **⌘J** 尝试。详情见 [AI 助手](./ai)。

## Git 不可用或远端操作失败

| 现象 | 检查内容 |
| --- | --- |
| 找不到 Git | 系统已安装并能够找到 Git |
| 未检测到仓库 | 打开的文件或文件夹属于 Git 仓库 |
| 没有预期变更 | 文件已写入磁盘，也检查是否被忽略 |
| 提交失败 | Git 作者名称与邮箱已配置 |
| 推送或拉取失败 | 远端地址、网络、认证和分支权限 |
| 变更冲突 | 处理并保存冲突，再继续操作 |

Git 远端使用 Git 身份验证，不使用 AI API key。正常的暂存与提交流程见 [Git 工作流](./git)。

## 图片无法显示

在源码模式中检查图片路径。相对路径必须对应文档当前位置；移动文件可能导致路径失效。确认图片存在且能打开。

在线图片需要检查 URL 和网络访问；上传图片还需检查存储配置，以及目标读者是否能访问链接。

分享 Markdown 或 HTML 时，同时提供引用的本地资源。详情见[图片资源管理](./files#管理图片资源)。

## 导出内容缺失或版式不符合预期

1. 确认内容在可视化编辑器中正确显示。
2. 修复缺失图片、公式或 Mermaid 错误。
3. 检查 **设置 → 导出** 中的纸张、页边距和目录。
4. 尝试更宽的页面，或简化过宽表格与过长代码行。
5. 重新导出，在对应查看器中检查。

PDF 应逐页检查，而不只看第一页。详情见[导出文档](./export)。

## 界面或快捷键异常

按 **⌘0** 恢复默认缩放，尝试内置字体，并检查外观中的界面缩放。通过 **显示** 菜单恢复隐藏的工具栏或侧边栏。

快捷键异常时，先让编辑器获得焦点，再对照应用内的快捷键参考。部分控件会采用不同的按键处理方式。详情见[外观与设置](./appearance)和[键盘快捷键](./shortcuts)。

## 反馈可复现的问题

提供“关于”中的 Mark2 版本、macOS 版本、操作步骤、预期结果和准确的错误文字。相关时可以附上移除私密内容的最小示例文档。

分享截图或日志前，移除 API key、私密路径和敏感内容。使用 [Mark2 项目页面](https://github.com/mark2-editor/mark2)列出的反馈渠道。
